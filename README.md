## About

I am a software engineer with 5+ years of experience building enterprise backend systems and cloud services, including time at Goldman Sachs, Morgan Stanley, Meta Innovation Technologies and Accenture. My core stack is Java, Spring Boot and AWS. I am now applying that engineering discipline to Python-based machine learning and LLM applications: retrieval-augmented generation, agent workflows and automation.

**What I build:** REST APIs and microservices, cloud-hosted backends, full-stack web applications, and AI-powered tools that automate real workflows.

**How I work:** keep designs simple, test what matters, containerize everything, and ship small, measurable improvements. I would rather deliver a reliable service than an impressive demo.

Most of my enterprise work is proprietary, so this profile shows my recent public projects. I am open to Senior Software Engineer, Backend, AWS Cloud and AI Engineer roles, as well as consulting work.
